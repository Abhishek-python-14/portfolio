# Abhishek | Full Stack Developer Portfolio

Personal portfolio of Abhishek, a BCA student and Full Stack Developer with a focus on AI.

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Three.js.

## Sections

- Home with animated hero, 3D name card and skills
- About page with downloadable resume
- Projects: SHRAA (Android voice assistant) and Local Service Finder
- Contact form (opens WhatsApp) and social links

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
